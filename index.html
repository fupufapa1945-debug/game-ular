PANDUAN JADI APK

Game ini dibuat murni dengan HTML, CSS, dan JavaScript. Kamu bisa menjadikannya aplikasi Android (APK) menggunakan metode PWA Builder:

Langkah 1: Upload ke Hosting Web

Simpan file-file ini (index.html, style.css, script.js) ke web hosting publik seperti GitHub Pages, Netlify, atau Vercel.

Langkah 2: Buka PWABuilder

Buka situs pwabuilder.com di browser.

Langkah 3: Masukkan Link & Generate

Masukkan URL link website game kamu, lalu klik "Start" dan pilih "Generate" pada bagian Android.

Dibuat interaktif dengan HTML5 Canvas & Tailwind CSS
